# Synchronous 4-bit Up/Down Counter

## Project Overview
This project implements a synchronous 4-bit up/down counter using Verilog HDL. The counter increments or decrements based on the direction control input.

## Design Features
- 4-bit synchronous sequential counter
- Up and down counting modes
- Clock-driven state updates
- Verilog RTL implementation
- Functional verification using a testbench

## Simulation
The design was simulated in QuestaSim to observe the counter output during upward and downward counting.
